AlchemistDispatcher

class AlchemistDispatcher<P : Position<P>>(alchemistEnvironment: Environment<Any?, P>) : CoroutineDispatcher, Delay

Dispatcher that executes tasks immediately on the current thread and schedules delays and timeouts against Alchemist simulated time, where a time unit is a second.
