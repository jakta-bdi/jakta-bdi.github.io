suspend fun MutableAgentState<PrologBelief, PrologGoal>.askAllTo(receiver: AgentID, query: Struct, timeout: Duration? = null): List<Substitution>?

Extension function to send a message using the AskAll performative and wait for a reply. The agent will wait for the timeout duration for a reply from the receiver that matches the id of the question. The reply should be a Tell message with a List of beliefs that unify with the query. If a matching reply is received, the a List of Substitutions is returned. If no matching reply is received or the timeout is reached null is returned.
