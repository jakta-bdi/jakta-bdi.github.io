Intention

interface Intention : CoroutineContext.Element

Represents an intention in the agent. An intention is a logical sequence of actions that are executed by the agent to handle events: the intention can be formed by a stack of plans and sub-plans that are selected at runtime. An intention may suspend its execution between steps, allowing other intentions to run in a cooperative multitasking fashion. The agent schedules the execution of intention, running an atomic step of each intention when possible.

abstract val continuations: EventInbox<() -> Unit>

Channel of functions representing the continuation of the intention. When the intention resumes from a suspension point, the continuation is sent to this channel. This is used as a blocking queue of continuations to be executed when the intention is stepped.

abstract val job: Job

The Job of the intention, used to manage the lifecycle of the coroutines associated with the intention. The job is passed as the parent job of all coroutines launched as part of the intention. If the job is cancelled, all coroutines of the intention are also cancelled.
