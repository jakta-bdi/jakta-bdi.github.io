What is JaKtA?

JaKtA is a framework for programming intelligent agents with the Belief-Desire-Intention (BDI) architecture, built in Kotlin. Agents are plain Kotlin code, so there is no separate agent language to learn and you keep the tools you already love: your IDE, build tool, debugger and libraries.

If you use JaKtA in a research project, please cite it.

Multi Paradigm

Paradigm blending: mix Functional and Object-Oriented programming within your MAS codebase

Multi Platform

Write once, run on the JVM, in JavaScript, and natively on Linux, Windows, macOS and iOS

Configurable

Plug in the knowledge representation and the execution model, from coroutines to simulations

Hello, world!

Agents are written in pure Kotlin: their goals, beliefs and plans are declared with the DSL, and plan bodies are plain suspend Kotlin code.

  1. The agent starts with the goal "sayHello", a plain string.
  2. The plan triggered by adding that goal prints a message and stops the node.
  3. The MAS, one node with one agent, runs on Kotlin coroutines.

Add JaKtA to your Gradle build:

dependencies {
    implementation("it.unibo.jakta:jakta-core:<VERSION>")
    implementation("it.unibo.jakta:jakta-dsl:<VERSION>")
    implementation("it.unibo.jakta:jakta-api:<VERSION>")
}
Walk through the exampleTry the showcase in your browser
Agent.kt
val helloWorldAgent = agent<String, String, Any> {
    embodiedAs { Any() }
    hasInitialGoals {
        !"sayHello"
    }
    hasPlanLibrary {
        adding.goal {
            takeIf { it == "sayHello" }
        } triggers {
            agent.print("Hello, world!")
            node.terminateNode()
        }
    }
}

fun main(): Unit = runBlocking {
    mas(NodeBuilders.baseNode()) {
        node { withAgents(helloWorldAgent) }
    }.runLocally()
}
